Parse MachO

Usage:
  ipsw macho [flags]
  ipsw macho [command]

Aliases:
  macho, m

Available Commands:
  a2o         Convert MachO address to offset
  a2s         Lookup symbol at unslid address
  bbl         Create single universal/fat MachO out many MachOs
  disass      Disassemble ARM64 MachO at symbol/vaddr
  dump        Dump MachO data at given virtual address
  info        Explore a MachO file
  lipo        Extract single MachO out of a universal/fat MachO
  o2a         Convert MachO offset to address
  patch       Patch MachO Load Commands
  search      Find Mach-O files for given search criteria
  sign        Codesign a MachO

Flags:
  -h, --help   help for macho

Global Flags:
      --color           colorize output
      --config string   config file (default is $HOME/.config/ipsw/config.yaml)
      --no-color        disable colorize output
  -V, --verbose         verbose output

Use "ipsw macho [command] --help" for more information about a command.
